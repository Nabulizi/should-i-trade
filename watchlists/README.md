# Watchlists

Put TradingView watchlist exports (`.txt`, comma-separated `EXCHANGE:SYMBOL`
tokens) in this folder.

The dashboard prefers a personal export when one exists, otherwise it falls
back to the tracked `Watchlist_Example.txt`. Personal exports are local
trading context, so every `*.txt` here except the example is intentionally
ignored by Git and never ships with the repo or the public demo.
